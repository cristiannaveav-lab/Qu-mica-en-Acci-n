# Química en Acción

Libro digital interactivo de química para Primero Medio, protagonizado por Tato y el Profe Electrón.

## Publicación

Subir `index.html` a la raíz de este repositorio. Luego ir a **Settings → Pages → Build and deployment → Deploy from a branch**, seleccionar `main` y `/(root)`, y guardar.

Sitio previsto: https://cristiannaveav-lab.github.io/Qu-mica-en-Acci-n/

El HTML integra escenas, video, resumen, guía y evaluación.
